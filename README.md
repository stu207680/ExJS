# A-Posteriori Joint Schema Expansion for Empirical Research Knowledge in Computer Science

Research materials for a study extending a joint schema for empirical research practices to Machine Learning and Databases and Data-Intensive Systems. This repository contains the original and follow-up survey responses and definitions of the schema concepts.

## Publication

Patrik Thomas Michalski, Maximilian Britton, Andrea Maldonado, Moayad Almohaishi, Oliver Karras, Agnes Koschmider (2026). **A-Posteriori Joint Schema Expansion for Empirical Research Knowledge in Computer Science.** In *INFORMATIK 2026 – Digitale Resilienz*.

[DOI: 10.18420/inf2026_134](https://doi.org/10.18420/inf2026_134) · [Machine-readable citation](CITATION.cff)

## Using the materials

Open the spreadsheets in Excel, LibreOffice, or another XLSX reader. The response sheets are named “Form Responses 1” and “Formularantworten 1”; the first row contains the survey questions. Consult the definitions PDF and paper when interpreting the responses. This repository contains research materials, not an executable application.
